# پیکرهٔ ساختگی نمایشی

فایل‌های این پوشه با `write_synthetic_corpus` همین پروژه ساخته شده‌اند. متن‌ها شامل جمله‌های سادهٔ فارسی و انگلیسی، چند خط پایتون و متن ترکیبی‌اند. این داده‌ها فقط برای مشاهدهٔ خواندن فایل، ساخت دسته و اجرای کوتاه آموزش هستند و برای آموزش یک مدل زبانی عمومی کافی نیستند.

پیکره از اینترنت یا سند خصوصی گردآوری نشده است. برای فایل‌هایی که خودتان اضافه می‌کنید، حق استفاده و شرایط مجوز را جداگانه بررسی کنید، اطلاعات محرمانه را حذف کنید و نام فایل‌ها را صریحاً به برنامه بدهید. اسکریپت این پوشه یا زیرپوشه‌های دیگر را خودکار پیمایش نمی‌کند.
