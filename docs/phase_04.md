# فاز ۰۴ — لایهٔ خطی، فعال‌سازی و شبکهٔ پیش‌خور

در فاز سوم، شناسهٔ هر توکن و موقعیت آن به یک بردار اعشاری تبدیل شد. اکنون یاد می‌گیریم چگونه یک شبکهٔ کوچک این بردار را تغییر می‌دهد. تمام محاسبات روی CPU و با وزن‌های ساخته‌شده از ابتدا انجام می‌شوند. مثال آموزش نیز فقط از دادهٔ ساختگی محلی استفاده می‌کند.

## ۱. لایهٔ شبکهٔ عصبی چیست؟

لایه یک تبدیل روی ورودی است. بعضی لایه‌ها مانند لایهٔ خطی پارامتر قابل یادگیری دارند؛ بعضی مانند ReLU فقط یک تابع ثابت را اعمال می‌کنند. با کنار هم گذاشتن لایه‌ها، خروجی یک لایه ورودی لایهٔ بعدی می‌شود و گراف محاسباتی بزرگ‌تری ساخته می‌شود.

`ManualLinear` در این فاز بدون `nn.Linear` و با `torch.nn.Parameter`، `torch.matmul` و جمع بایاس پیاده‌سازی شده است:

`Y = XW + b`

اگر `X` شکل `(N, Din)` داشته باشد، وزن `W` شکل `(Din, Dout)` و بایاس `b` شکل `(Dout,)` دارد؛ خروجی `(N, Dout)` است. برای ورودی سه‌بعدی `(B, T, Din)`، ضرب روی محور آخر اعمال می‌شود و خروجی `(B, T, Dout)` خواهد بود. بایاس روی همهٔ نمونه‌ها و جایگاه‌ها پخش می‌شود.

توجه کنید در این پیاده‌سازی شکل وزن «تعداد ورودی × تعداد خروجی» است؛ شکل ذخیرهٔ وزن در `nn.Linear` برعکس این قرارداد است. این تفاوت فقط قرارداد ذخیره‌سازی است و باید هنگام کپی وزن‌ها در نظر گرفته شود.

## ۲. وزن و بایاس چه معنایی دارند؟

هر وزن تعیین می‌کند یک ویژگی ورودی چقدر و با چه علامتی در یک ویژگی خروجی سهم داشته باشد. بایاس یک مقدار جابه‌جایی مستقل از ورودی است. برای مثال:

`y = 1×x₁ + 2×x₂ + 0.5`

اگر `x₁=1` و `x₂=2` باشد، خروجی `5.5` خواهد بود. در آموزش، وزن‌ها و بایاس به کمک گرادیان تغییر می‌کنند. `nn.Parameter` باعث می‌شود این تنسورها در `module.parameters()` دیده شوند و به‌طور پیش‌فرض قابل مشتق‌گیری باشند.

مقدار اولیهٔ وزن‌ها و بایاس‌ها به‌صورت تصادفی یکنواخت در بازهٔ `[-1/√Din, +1/√Din]` انتخاب می‌شود. بذر ثابت در درس‌ها نتیجه را قابل تکرار می‌کند. خودِ کلاس‌ها بذر سراسری را تغییر نمی‌دهند.

## ۳. چرا چند لایهٔ خطی کافی نیست؟

لایهٔ دارای بایاس از نظر دقیق ریاضی «تبدیل آفین» است؛ در ادبیات شبکهٔ عصبی معمولاً آن را لایهٔ خطی می‌نامند. دو تبدیل متوالی بدون فعال‌سازی دوباره یک تبدیل آفین می‌سازند:

`(XW₁ + b₁)W₂ + b₂ = X(W₁W₂) + (b₁W₂ + b₂)`

پس افزودن لایه‌های بیشتر بدون تابع غیرخطی، توان بیان غیرخطی ایجاد نمی‌کند. در درس سیزدهم، لایهٔ اول از `x` دو ویژگی `[x, -x]` می‌سازد و لایهٔ دوم آن‌ها را جمع می‌کند. بدون فعال‌سازی، خروجی همیشه صفر است؛ با ReLU بین دو لایه، خروجی `max(0,x) + max(0,-x) = |x|` می‌شود. هیچ تبدیل آفین واحدی نمی‌تواند مقادیر قدرمطلق را هم در `-1`، هم در `0` و هم در `1` بسازد.

## ۴. ReLU چگونه کار می‌کند؟

`ReLU(x) = max(0, x)`

برای ورودی‌های `[-2, 0, 3]` خروجی `[0, 0, 3]` است. مشتق برای مقدار مثبت ۱ و برای مقدار منفی صفر است. در صفر، مشتق ریاضی یکتا نیست؛ پیاده‌سازی ما همانند ReLU متداول، مقدار صفر را برای پس‌انتشار انتخاب می‌کند. استفاده از `torch.where(x > 0, x, 0)` این رفتار را مشخص می‌کند.

ReLU تابعی ساده و غیرخطی است. یکی از محدودیت‌های آن این است که در سمت منفی گرادیان صفر دارد؛ بنابراین بعضی واحدها ممکن است برای ورودی‌های حاضر تغییر نکنند.

## ۵. GELU چگونه کار می‌کند؟

GELU ورودی را با تابع توزیع تجمعی نرمال استاندارد، یعنی `Φ`، وزن‌دهی می‌کند:

`GELU(x) = x × Φ(x)`

`Φ(x) = 0.5 × (1 + erf(x / √2))`

در نتیجه پیاده‌سازی دقیق ما چنین است:

```python
0.5 * x * (1.0 + torch.erf(x / math.sqrt(2.0)))
```

این تابع هموار است و مقدارهای منفی را مانند ReLU ناگهان صفر نمی‌کند. مثلاً `GELU(-1)` حدود `-0.1587` و `GELU(1)` حدود `0.8413` است. این محاسبه تصادفی نیست؛ از تابع نرمال فقط به‌عنوان یک فرمول ثابت استفاده می‌شود. هر دو فعال‌سازی بدون پارامتر قابل یادگیری‌اند و شکل ورودی را حفظ می‌کنند.

## ۶. شبکهٔ پیش‌خور چگونه بردارها را تغییر می‌دهد؟

شبکهٔ این فاز سه مرحله دارد:

```text
(B, T, 128) → ManualLinear → (B, T, 512)
                              ↓ GELU
(B, T, 128) ← ManualLinear ← (B, T, 512)
```

رابطهٔ آن:

`FFN(X) = GELU(XW₁ + b₁)W₂ + b₂`

ابتدا ویژگی‌های هر بردار در فضای بزرگ‌تری ترکیب می‌شوند، سپس فعال‌سازی غیرخطی اعمال می‌شود و در پایان بردار به بُعد اولیه برمی‌گردد. وزن‌ها بین همهٔ نمونه‌ها و جایگاه‌ها مشترک‌اند. خودِ FFN اطلاعات یک جایگاه را با جایگاه‌های دیگر مخلوط نمی‌کند؛ هر بردار جداگانه پردازش می‌شود.

```python
import torch
from minicoder.config import DEVICE, EMBEDDING_DIM, SEED
from minicoder.model import FeedForward

torch.manual_seed(SEED)
x = torch.randn(2, 4, EMBEDDING_DIM, device=DEVICE)
network = FeedForward()
y = network(x)
print(tuple(y.shape))  # (2, 4, 128)
```

هر لایهٔ دستی ورودی دوبعدی یا سه‌بعدی می‌پذیرد. خودِ `FeedForward` برای قرارداد دنباله فقط ورودی سه‌بعدی می‌پذیرد. بُعد آخر باید با بُعد ورودی لایه برابر باشد و نوع اعشاری ورودی با وزن‌ها یکسان باشد. مقدار پیش‌فرض `float32` است؛ برای ورودی `float64` می‌توان ابتدا `network.double()` را فراخوانی کرد.

## ۷. شمارش پارامترها

لایهٔ دارای `Din` ورودی و `Dout` خروجی، `Din × Dout + Dout` پارامتر دارد:

| بخش | شکل | تعداد پارامتر |
| --- | --- | ---: |
| وزن اول | `128 × 512` | ۶۵٬۵۳۶ |
| بایاس اول | `512` | ۵۱۲ |
| GELU | بدون پارامتر | ۰ |
| وزن دوم | `512 × 128` | ۶۵٬۵۳۶ |
| بایاس دوم | `128` | ۱۲۸ |
| مجموع | | ۱۳۱٬۷۱۲ |

این شمارش فقط مربوط به FeedForward است و پارامترهای embedding را شامل نمی‌شود. ویژگی `trainable_parameter_count` در `ManualLinear` و `FeedForward` پارامترهای قابل یادگیری را می‌شمارد. درس چهاردهم نتیجهٔ فرمول را با جمع `p.numel()` برای پارامترهای PyTorch مقایسه می‌کند. اندازهٔ دسته و طول دنباله تعداد پارامترها را تغییر نمی‌دهند.

## ۸. گرادیان چگونه از چند لایه عبور می‌کند؟

مراحل گذر رو به جلو را به‌شکل `Z = XW₁ + b₁`، `A = GELU(Z)` و `Y = AW₂ + b₂` بنویسیم. فرض کنید مشتق خطا نسبت به خروجی `G = ∂L/∂Y` باشد. برای نوشتن سادهٔ روابط، محورهای دسته و دنباله را در یک محور نمونه ادغام می‌کنیم:

`∂L/∂W₂ = AᵀG`

`∂L/∂b₂ = جمع G روی نمونه‌ها`

`∂L/∂Z = (GW₂ᵀ) ⊙ GELU'(Z)`

`∂L/∂W₁ = Xᵀ(∂L/∂Z)`

`∂L/∂b₁ = جمع ∂L/∂Z روی نمونه‌ها`

علامت `⊙` ضرب عضو به عضو است. این روابط همان قانون زنجیره‌ای‌اند؛ `loss.backward()` آن‌ها را از طریق گراف محاسباتی محاسبه می‌کند. گرادیان می‌تواند از ورودی FFN نیز عبور کند و در صورت اتصال به embedding، به جدول‌های فاز سوم برسد.

## ۹. آموزش با دادهٔ ساختگی

درس پانزدهم هشت بردار با شکل کلی `(2, 4, 128)` در حافظه می‌سازد. هدف `tanh(x)` و خطا میانگین مربع فاصلهٔ خروجی و هدف است. هیچ متن یا مجموعه‌داده‌ای برای آموزش خوانده نمی‌شود. برای هر یک از ۸۰ گام:

1. گرادیان‌های گام قبل پاک می‌شوند.
2. گذر رو به جلو و محاسبهٔ خطا انجام می‌شود.
3. `backward()` گرادیان وزن‌ها و بایاس‌های هر دو لایه را می‌سازد.
4. پارامترها به‌صورت دستی تغییر می‌کنند.

```python
network.zero_grad()
prediction = network(inputs)
loss = (prediction - targets).square().mean()
loss.backward()

with torch.no_grad():
    for parameter in network.parameters():
        parameter -= learning_rate * parameter.grad
```

گرادیان جهت تغییر خطا نسبت به پارامتر را نشان می‌دهد. کم کردن ضریبی از آن، با نرخ یادگیری مناسب، می‌تواند خطا را کاهش دهد. `no_grad` باعث می‌شود خودِ به‌روزرسانی وارد گراف مشتق‌گیری نشود. درس، وزن‌های اولیه و نهایی، مقدار گرادیان‌ها و خطای قبل و بعد را چاپ می‌کند. کاهش خطا فقط برازش همین نمونه‌ها را نشان می‌دهد؛ عملکرد روی دادهٔ جدید اندازه‌گیری نشده است.

در اجرای ثبت‌شده با بذر ۴۲ و نرخ یادگیری ۰٫۱، خطای اولیه حدود `0.44479` و خطا پس از ۸۰ گام حدود `0.02536` بود. شکل ورودی و خروجی هر دو `(2, 4, 128)` باقی ماند و گرادیان وزن و بایاس هر دو لایه غیرصفر بود.
