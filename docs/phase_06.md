# فاز ۰۶ — توجه علّی چندسر

یک سر توجه در هر جایگاه یک توزیع احتمال روی گذشته می‌سازد. چند سر اجازه می‌دهند چند توزیع متفاوت به‌صورت همزمان ساخته شوند. ممکن است پس از آموزش هر سر به الگوی متفاوتی حساس شود؛ هیچ نقش زبانی مشخصی از ابتدا به سرها اختصاص داده نشده است.

## از یک بردار به چهار سر

با `D=128` و `H=4`، بُعد هر سر `d=D/H=32` است. ابتدا سه تصویر کامل `Q`، `K` و `V` با شکل `(B,T,128)` می‌سازیم. هر تصویر سپس به‌شکل زیر تغییر آرایش می‌دهد:

```text
(B,T,128)
  reshape → (B,T,4,32)
  transpose(1,2) → (B,4,T,32)
```

برای نمونه، سر صفر ۳۲ ویژگی اولِ تصویر و سر یک ۳۲ ویژگی بعدی را می‌گیرد. چون خودِ تصویرها آموختنی‌اند، این تقسیم معادل تقسیم ثابت متن به چهار قسمت نیست. همهٔ سرها تمام جایگاه‌های مجازِ دنباله را می‌بینند.

برای هر سر:

`S_h = Q_h K_hᵀ / √32`

`A_h = softmax(mask(S_h))`

`Y_h = A_h V_h`

شکل امتیازها و احتمال‌ها `(B,4,T,T)` است. ماسک علّی مستقل روی همهٔ سرها و نمونه‌ها اعمال می‌شود. هستهٔ امتیازدهی و ماسک همان کد فاز پنجم است؛ پیاده‌سازی آمادهٔ توجه استفاده نمی‌شود.

## اتصال و تصویر خروجی

خروجی سرها شکل `(B,4,T,32)` دارد. محورهای سر و زمان را دوباره جابه‌جا می‌کنیم، حافظه را پیوسته می‌کنیم و دو محور ویژگی را کنار هم می‌گذاریم:

```text
(B,4,T,32)
  transpose(1,2) → (B,T,4,32)
  contiguous + reshape → (B,T,128)
  تصویر خروجی → (B,T,128)
```

رابطهٔ نهایی `Y = concat(Y₀,Y₁,Y₂,Y₃)Wo + bo` است. تصویر خروجی اجازه می‌دهد ویژگی‌های ساخته‌شده توسط سرهای مختلف با هم ترکیب شوند. یک تست عددی، توجه هر سر را با حلقه و ضرب‌های داخلی کوچک محاسبه می‌کند و هم اتصال و هم تصویر خروجی را با نتیجهٔ ماژول می‌سنجد.

```python
import torch
from minicoder.model import MultiHeadCausalAttention

attention = MultiHeadCausalAttention()
x = torch.randn(2, 5, 128)
heads = attention.split_heads(x)
assert heads.shape == (2, 4, 5, 32)
assert torch.equal(attention.merge_heads(heads), x)
y, probabilities = attention(x, return_attention=True)
# y: (2,5,128) و probabilities: (2,4,5,5)
```

`embedding_dim` باید بر `num_heads` بخش‌پذیر باشد و هر دو عدد صحیح مثبت باشند. سقف طول، CPU، نوع اعشاری، ورودی متناهی و قرارداد شکل مانند فاز پنجم بررسی می‌شوند.

## پارامترها و هزینهٔ محاسبه

چهار تصویر کامل دارای بایاس داریم: Q، K، V و خروجی. تعداد پارامترها `4(D²+D)` و در تنظیمات پیش‌فرض برابر ۶۶٬۰۴۸ است. در بُعد ثابت ۱۲۸، تغییر تعداد سرها این تعداد پارامتر را تغییر نمی‌دهد، زیرا بُعد هر سر در مقابل تغییر می‌کند.

هزینهٔ ضرب‌های توجه در مرتبهٔ `B × T² × D` و هزینهٔ تصویرهای کامل در مرتبهٔ `B × T × D²` است. فضای احتمال‌ها با `B × H × T²` رشد می‌کند؛ دو برابر شدن طول دنباله تقریباً چهار برابر خانهٔ توجه می‌خواهد. محاسبات داخلی `float64` حافظه و زمان بیشتری از `float32` می‌گیرند؛ برای سقف ۱۲۸ و پروژهٔ آموزشی CPU این انتخاب آگاهانه است.
