# فاز ۰۵ — توجه علّی تک‌سر

بردار یک توکن تا فاز قبل عمدتاً به‌صورت مستقل پردازش می‌شد. توجه اجازه می‌دهد خروجی هر جایگاه از محتوای چند جایگاه ساخته شود. در یک مدل زبانی علّی، فقط خودِ جایگاه و گذشتهٔ آن مجازند؛ دسترسی به آینده هنگام آموزش پاسخ را لو می‌دهد.

## Query، Key و Value

از ورودی `X` با شکل `(B,T,D)` سه تصویر قابل یادگیری می‌سازیم:

`Q = XWq + bq`، `K = XWk + bk`، `V = XWv + bv`

هر کدام شکل `(B,T,D)` دارد. Query را می‌توان پرسشِ جایگاه فعلی، Key را نمایهٔ تطبیق هر جایگاه و Value را محتوای قابل ترکیب دانست. این نام‌ها نقش محاسباتی‌اند؛ وزن‌های تصادفی هنوز مفهوم زبانی مشخصی ندارند. سه تصویر از `ManualLinear` فاز چهارم استفاده می‌کنند.

## امتیاز و احتمال توجه

امتیاز توجه بین Query جایگاه `i` و Key جایگاه `j` از ضرب داخلی ساخته می‌شود:

`S[i,j] = dot(Q[i], K[j]) / √D`

تقسیم بر جذر بُعد، مقیاس معمولِ ضرب داخلی را هنگام افزایش بُعد کنترل می‌کند. `Q @ K.transpose(-2,-1)` شکل `(B,T,T)` دارد؛ سطر مربوط به Query و ستون مربوط به Key است.

مثلاً اگر `q=[1,0]` و دو Key برابر `[1,0]` و `[0,1]` باشند، امتیازها `[1/√2,0]` می‌شوند. اگر هر دو جایگاه مجاز باشند، softmax تقریباً `[0.6698,0.3302]` می‌دهد. اگر Valueها `[10,0]` و `[0,20]` باشند، خروجی تقریباً `[6.698,6.605]` است. احتمال‌ها به‌عنوان وزنِ محتوا به کار می‌روند، نه خودِ امتیاز خام.

`softmax(s)[j] = exp(s[j] - max(s)) / Σ exp(s[k] - max(s))`

کم کردن بیشینه باعث می‌شود محاسبهٔ نمایی سرریز نکند. PyTorch این نرمال‌سازی را پایدار انجام می‌دهد. جمع هر سطر احتمال برابر یک است.

## ماسک علّی باید پیش از softmax اعمال شود

خانه‌هایی با `j > i` به آینده اشاره دارند. آن‌ها را پیش از softmax با منفی بی‌نهایت جایگزین می‌کنیم:

```text
مجاز = [[1,0,0],
        [1,1,0],
        [1,1,1]]
```

چون `exp(-∞)=0` است، آینده دقیقاً احتمال صفر می‌گیرد. قطر اصلی باز است، بنابراین هیچ سطری کاملاً مسدود نیست. صفر کردن امتیاز خام کافی نیست، چون `exp(0)=1` است. صفر کردن احتمال‌ها پس از softmax نیز جمع هر سطر را خراب می‌کند.

خروجی از رابطهٔ `Y = A @ V` با شکل `(B,T,D)` ساخته می‌شود. در تک‌سر این فاز تصویر خروجیِ اضافه نداریم. سه تصویر دارای بایاس، در بُعد ۱۲۸ مجموعاً `3 × (128²+128) = 49,536` پارامتر دارند. ماسک یک بافر ثابت است و پارامتر یادگرفتنی نیست.

## پایداری عددی و قرارداد ماژول

برای محاسبات کوچک CPU، ضرب امتیازها، softmax و ترکیب Valueها در داخل با `float64` انجام می‌شود؛ خروجی و وزن‌های توجه به نوع ورودی برمی‌گردند. این کار از سرریز زودهنگام ضرب بردارهای بزرگ `float32` جلوگیری می‌کند. این تبدیل مسیر گرادیان را قطع نمی‌کند. ورودی غیرمتناهی یا سرریزِ خارج از ظرفیت `float64` با خطا رد می‌شود؛ دقت بالاتر ظرفیت نامحدود ایجاد نمی‌کند.

ورودی باید تنسور اعشاری CPU با شکل `(B,T,D)`، نوع یکسان با وزن‌ها و دسته و طول غیرصفر باشد. سقف طول از `MAX_CONTEXT_LENGTH` خوانده می‌شود. طول‌های کمتر از سقف و دسته‌های متفاوت پشتیبانی می‌شوند.

```python
import torch
from minicoder.model import CausalSelfAttention

attention = CausalSelfAttention()
x = torch.randn(2, 5, 128)
y, probabilities = attention(x, return_attention=True)
# y: (2,5,128) و probabilities: (2,5,5)
loss = y.square().mean()
loss.backward()
print(attention.query.weight.grad.norm())
```

فراخوانی پیش‌فرض فقط خروجی را برمی‌گرداند؛ `return_attention=True` احتمال‌ها را نیز برای بررسی آموزشی برمی‌گرداند. وزن‌های Q، K و V از خطای خروجی گرادیان می‌گیرند. تغییر ورودیِ آینده نه خروجی قبلی را تغییر می‌دهد و نه از خطای گذشته گرادیانی به آینده می‌فرستد؛ هر دو رفتار تست شده‌اند. بایاس Key در این فرمول می‌تواند گرادیان صفر یا بسیار کوچک داشته باشد، چون افزودن یک بردار ثابت به تمام Keyها به هر سطر امتیاز یک مقدار مشترک می‌افزاید و softmax آن را حذف می‌کند.
