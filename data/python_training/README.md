# پیکرهٔ آموزشی پایتون ۱٫۱

این فایل‌ها به‌طور محلی از ۱۲۰ الگوی نوشته‌شده برای همین پروژه، با بذر ثابت ۱۱۰۱ ساخته شده‌اند. دانلود یا کپی از پیکرهٔ بیرونی انجام نشده است. فایل‌های `.py` دادهٔ متنی‌اند و برای تولید یا اعتبارسنجی اجرا نمی‌شوند.

| بخش | نمونه | خانوادهٔ ساختاری مستقل | نمونه در هر موضوع |
| --- | ---: | ---: | ---: |
| train | ۳۲۰ | ۸۰ | ۳۲ |
| validation | ۴۰ | ۲۰ | ۴ |
| test | ۴۰ | ۲۰ | ۴ |

هر ده موضوع در هر سه بخش حضور دارد: متغیر و حساب، تابع، شرط، for، while، لیست و دیکشنری، رشته، کلاس، الگوریتم و تمرین کوتاه. هر خانوادهٔ train چهار گونهٔ نام/مقدار و هر خانوادهٔ validation یا test دو گونه دارد. خانواده‌ها بین بخش‌ها مشترک نیستند. طول واقعی مثال‌ها ۱۳ تا ۱۰۳ بایت است؛ با BOS/EOS حداکثر ۱۰۵ توکن می‌شوند و در زمینهٔ ۱۲۸تایی جا می‌گیرند.

`manifest.json` فهرست صریح فایل‌ها، نقش بخش، موضوع، خانواده، بذر و هش‌های محتوا و ساختار را دارد. `quality_report.json` نتیجهٔ بررسی اولیه است. برای بررسی تازه:

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/prepare_python_dataset.py --validate-only
```

این فرمان را از ریشهٔ `MiniCoderBrain` اجرا کنید. بازتولید در مسیر موجود انجام نمی‌شود؛ برای مقایسهٔ قطعی مسیر تازه بدهید. روش ساخت و فرمان‌های آموزش در [راهنمای ۱٫۱](../../docs/version_1_1_python_training.md) آمده است.

بررسی شامل نحو، UTF-8، اندازه، تکرار عین و بدون تفاوت فاصله، نشت AST مقاوم به تغییر نام و مقدار، تطبیق manifest با بذر و فایل اضافه/جاافتاده است. کدها کوتاه و مقدماتی‌اند؛ اعتبار نحوی اثبات صحت عملکرد برای همهٔ ورودی‌ها نیست. مثلاً `largest` و `smallest` فهرست غیرخالی می‌خواهند، `factorial` و `fib` ورودی صحیح نامنفی فرض می‌کنند، `clamp` حد پایینِ کوچک‌تر یا مساوی حد بالا دارد و تمرین `invert` مقدارهای یکتا می‌خواهد.

پیکره برای آزمایش محدود و آموزشی است و به‌تنهایی مدل عمومی برنامه‌نویسی نمی‌سازد. validation برای انتخاب تنظیمات است؛ test را فقط پس از انتخاب نهایی ارزیابی کنید. نتیجهٔ بهبود تولید هنوز برای این پیکره گزارش نشده است.
